What is a div element?

The div element is a like bucket that groups sections of a webpage together.

What is one way you can identify or "target" a div element?

A div can be identified or “targeted” in several different ways. One way is, classes. When you are calling a class in CSS, it will target every div with the same class.

Why would you use a div element?

A div element is used in HTML to group related content together so it can be easily styled, organized, or controlled with CSS and JavaScript.

What is a border property?

The border property allows you to style the border around an element. The border indicates the size of an element.

What are some of the different border properties?

Border width, Border color, Border sides, Rounded borders

What is the difference between margins and padding?

A margin is the spacing around an element from everything around it. A margin is the spacing around an element from everything around it.
